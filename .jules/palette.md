## 2024-11-01 - Add Ingredient Card Accessibility
**Learning:** Found an interactive "Add Ingredient" card that uses `motion.div` with `cursor-pointer` but lacks semantic button properties, focus styles, and ARIA labels. This is a common pattern where developers use divs for complex interactive components instead of buttons, breaking keyboard navigation and screen reader support.
**Action:** When finding complex interactive elements built with divs/motion.divs, convert them to `<motion.button type="button">`, remove default outline (`focus:outline-none`), add custom focus rings (`focus-visible:ring-2 focus-visible:ring-primary`), and hide decorative icons (`aria-hidden="true"`).
